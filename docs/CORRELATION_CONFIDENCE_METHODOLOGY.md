# Correlation confidence methodology

There is no numerical confidence and no probability of guilt.

These stay separate on the proposal:

| Question | Where it is |
| --- | --- |
| How exact is the identifier? | The rule name: exact host, exact address, exact reference. Similar text does not match. |
| How reliable is the source? | `verified` means a stored field states the claim. It does not grade the bank or the resolver. |
| Are the sources independent? | Support lists the transaction ids and observation ids. A narration and a DNS row are different records. Two DNS rows that share an address are co-occurrence, not two owners. |
| Does time agree? | Time is stored and displayed. It is not a match rule. |
| What is missing? | The limitation text. Registration, certificates, and ASN are `not_collected`. |
| What else could explain it? | The overlap sentence: shared hosting, a shared address, or shared DNS does not establish common ownership, common control, or a common operator. |
| What did the investigator decide? | `proposed`, `confirmed`, or `rejected`, plus the review history. |

A score is not justified. There is no calibration set that is separate from
these rules, and a number would be read as the chance that a person committed
an offence.
