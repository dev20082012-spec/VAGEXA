# Hackathon MVP scope

Frozen on 2026-11-22 for the 24 November 2026, 23:00 IST deadline.

The long-term platform stays. The submission is one synthetic investigation a
judge can open without uploading a file.

## In the demo

- Sign in as the seeded investigator.
- Land on that investigation, not an empty register.
- See reference, synthetic label, transaction count, trace status, findings,
  and the non-guilt limitation.
- Open the transaction list already filled.
- Open the FIFO result already run: three hops and `outside_horizon` on the
  last intermediary. Account B is not the attributed beneficiary.
- Open fan-in and fan-out already run, with support ids and the rule-match
  wording.
- Open domains, the shared address, and the overlap limitation.
- Open one `mentioned_in` proposal: a narration contains `syn-a.test`, and a
  DNS observation of that name is in the case. Status stays `proposed` until
  the judge confirms it. Assertion stays `verified` for containment only.
- Open the graph drawn from those stored rows.
- Read an in-app summary assembled from those API responses.

## Out of the demo

- Live DNS, RDAP, certificates, ASN, geolocation.
- Copilot and any model.
- PDF export, unless the in-app summary is already done and time remains.
- A second investigation story.
- Centrality, community detection, cycle labels, risk scores.
- Public registration, email reset, extra roles.
- Neo4j or any new database.

## Judge path

1. Sign in.
2. The seeded case is selected.
3. Read the summary and the synthetic banner.
4. Transactions, then the trace residual.
5. Indicators.
6. Infrastructure and the overlap sentence.
7. The narration bridge, still proposed.
8. The graph.
9. Confirm or leave the proposal. The source narration does not change.

If a step requires the judge to upload a CSV or invent a domain, the demo is
not ready.
